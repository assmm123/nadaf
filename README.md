# متجر NADAF | نداف 🛍️

متجر إلكتروني متكامل لبيع الكرافات والأطقم الرسمية والإكسسوارات — مبني بـ **Laravel 13 + Livewire 3 + Filament 3** كمشروع واحد متكامل (بدون API منفصل) مع دعم كامل للغتين العربية/الإنجليزية والعملتين (دولار/ليرة سورية) وPWA قابل للتثبيت.

## التشغيل محليًا

```bash
php artisan serve          # ثم افتح http://localhost:8000
```

> بيئة جهازك: PHP 8.3 مثبت في `E:\tools\php83` وComposer في `E:\tools\composer.phar` — التشغيل:
> `E:\tools\php83\php.exe artisan serve`
> قاعدة البيانات: SQLite جاهزة (`database/database.sqlite`) — لا تحتاج MySQL محليًا.

### الحسابات الجاهزة

| الدور | البريد | كلمة المرور |
|------|--------|-------------|
| مدير المتجر | `admin@nadaf.store` | `admin123` |
| عميل تجريبي | `customer@nadaf.store` | `customer123` |

- واجهة المتجر: `http://localhost:8000`
- لوحة الأدمن: `http://localhost:8000/admin`

### بناء الواجهة عند تعديل CSS/JS

```

### إعادة تهيئة البيانات التجريبية

```

## أبرز الميزات

### واجهة العميل
- **ثنائية اللغة** (عربي RTL / إنجليزي) مع تبديل فوري من الهيدر، وثنائية العملة (دولار أساس التسعير، الليرة تُحسب تلقائيًا من سعر الصرف مع تجاوز يدوي اختياري لكل منتج).
- **منتجات بمتغيرات**: لون/مقاس مع مخزون مستقل لكل متغير وحد تنبيه انخفاض، ومنتجات بلا متغيرات (متوفرة دائمًا).
- **وسائط**: صور متعددة بترتيب وصورة رئيسية + فيديو قصير (يتحقق النظام من المدة ≤ 10 ثوانٍ عبر getID3).
- **زر استفسار** لكل منتج (يُفعَّل/يُعطَّل لكل منتج وعالميًا) يعرض وسائل التواصل التي يحددها الأدمن بروابط جاهزة (wa.me / t.me / m.me / mailto / tel).
- **سلة وطلبات**: السلة بجلسة العميل، إتمام الطلب يتطلب حسابًا، اختيار استلام من المحل (مجاني) أو توصيل محلي (أجرة من الإعدادات)، وسيلة دفع مع تفاصيلها، كوبون خصم.
- **أسعار الجملة**: حقل سعر جملة لكل منتج يُطبَّق تلقائيًا عند بلوغ الحد الأدنى للكمية (لكل عنصر) أو قيمة الطلب.
- **إثبات الدفع قبل توليد الكود**: كل وسيلة دفع لها خيار «تتطلب إثبات دفع» من اللوحة — الوسائل التي تتطلبه يُطلب من العميل فيها **رقم الحوالة أو رفع صورة/PDF الإيصال (أحدهما على الأقل)** + اسم المرسل قبل إصدار كود الطلب، والإثبات يظهر للأدمن في صفحة الطلب مع صورته ويُرسل **صورة الإيصال نفسها** في إشعار تيليجرام.
- **تفاصيل وسائل الدفع الموسعة**: للأدمن حقول IBAN (بتحقق صيغة) وصورة باركود/QR وتعليمات حرة لكل وسيلة — تظهر للعميل في لوحة أنيقة عند الاختيار، مع أيقونة معبّرة لكل نوع (محفظة/بنك/نقدي).
- **إتمام طلب احترافي**: 4 خطوات مرقمة (استلام ← دفع ← إثبات ← خصومات)، حقل **المدينة** إلزامي للتوصيل المحلي، ورسالة شكر شخصية باسم العميل «سيتم الرد عليك في أسرع وقت».
- **حساب العميل**: الملف الشخصي، الطلبات السابقة مع حالتها وسجل تغيّرها.
- **PWA**: manifest + Service Worker + أيقونات مولّدة + صفحة عدم اتصال + زر تثبيت.
- سلايدر (صور/فيديو)، بحث، فلاتر (لون/مقاس/سعر) وترتيب، صفحات ثابتة، اتصل بنا.

### لوحة الأدمن (Filament)
- **إحصائيات**: المبيعات، الطلبات الجديدة، المنتجات، العملاء + رسم بياني للطلبات آخر 30 يومًا + آخر الطلبات.
- **إدارة كاملة**: منتجات (متغيرات ووسائط داخل النموذج)، أقسام رئيسية/فرعية، طلبات (عرض تفصيلي يشمل **إثبات الدفع وصورته ورقم الحوالة** + **تغيير الحالة مع سجل** + **فاتورة**: طباعة، تحميل كصورة PNG، وإرسال نص الفاتورة للعميل عبر واتساب)، وسائل دفع وتواصل، كوبونات، مستخدمون (حظر/تنشيط)، سلايدر، صفحات ثابتة.
- **ختم التوثيق الرسمي**: بعد اعتماد الطلب يظهر زر «ختم التوثيق» الذهبي — يختم الطلب بختم دائري ذهبي فخم (ربطة عنق كبيرة بتفاصيل طية في المركز، اسم المتجر أعلى الإطار قابل للتعديل من الإعدادات، والتاريخ والوقت الحقيقي أسفله)، وتسجل العملية في سجل الطلب.
- **فاتورة بوضعين متمايزين**: قبل الختم = **«إيصال طلب»** بهيدر فاتح وإطار متقطع وعبارة «وثيقة مبدئية — قيد المراجعة»؛ بعد الختم = **«فاتورة نظامية معتمدة»** بهيدر كحلي متدرج وشريط ذهبي والختم في الأسفل — كلٌّ بطباعته وهويته (أزرار: طباعة / تحميل كصورة PNG / إرسال واتساب بنص منسق).
- **نظام الجرد الكامل**: سجل حركات المخزون (بيع/إرجاع/استلام/تسوية/تالف) بالرصيد قبل وبعد والمرجع، **إلغاء الطلب يرجع الكميات تلقائيًا**، **فواتير الشراء** (مسودة ← تأكيد يضيف للمخزون ويحدّث التكلفة)، **الموردون**، وصفحة **الجرد الفعلي** (عدّ فعلي ← تسوية الفروقات بحركة موثقة).
- **تنبيهات تيليجرام موسعة**: قناتان منفصلتان (الطلبات / الجرد)، صورة إثبات الدفع داخل إشعار الطلب، تحديثات تغيير الحالة، تنبيه انخفاض المخزون ونفاده، وإشعار استلام الشراء — مع خيار «تعطيل تحقق SSL» لحل خطأ self-signed certificate خلف برامج VPN/مضادات الفيروسات.
- **السجلات والأرباح**: صفحة تقارير بفترات (يومي/أسبوعي/شهري/مخصص) تعرض المبيعات والأرباح المقدّرة (بحقل تكلفة الشراء لكل منتج) وتوزيعها حسب القسم والمنتج والسجل اليومي، مع **تصدير CSV وExcel (XLSX متعدد الأوراق) وPDF (طباعة)**.
- **الإعدادات العامة**: اسم المتجر وهاتفه، سعر الصرف، الشحن، حدود الجملة، تفعيل الاستفسار، نص الختم، **إشعارات الطلبات عبر تيليجرام (مع زر اختبار) والبريد الإلكتروني**.
- مع كل طلب يُثبَّت **سعر الصرف لحظته** فلا تتأثر الطلبات القديمة بتغير السعر.
- عند إنشاء الطلب: يُخصم المخزون، يُحسب استخدام الكوبون، ويُرسل بريد للعميل وإشعار للمتجر (تيليجرام/بريد حسب الإعدادات).

## الإعدادات المطلوبة قبل الإطلاق الفعلي

1. من لوحة الأدمن → **الإعدادات العامة**: عدّل سعر الصرف وأجرة التوصيل وبيانات المتجر.
2. **وسائل الدفع**: عدّل أرقام شام كاش والحسابات الحقيقية (البيانات الحالية تجريبية).
3. **وسائل التواصل**: ضع أرقام المتجر الحقيقية.
4. **إشعارات تيليجرام**: أنشئ بوتًا من [@BotFather](https://t.me/BotFather) → انسخ التوكن → أرسل رسالة للبوت → احصل على `chat_id` من `https://api.telegram.org/bot{TOKEN}/getUpdates` → فعّل الإشعار وجرّب زر الاختبار.
5. **البريد الإلكتروني**: اضبط `MAIL_*` في `.env` (مثل Brevo المجاني: 300 رسالة يوميًا) وفعّل الإشعار من الإعدادات.
6. عدّل محتوى **الصفحات الثابتة** (من نحن، سياسة الاستبدال، الأسئلة الشائعة).

## بنية المشروع المهمة

```
app/
├── Filament/            # لوحة الأدمن (Resources, Pages, Widgets)
├── Http/Controllers/    # متحكمات واجهة المتجر
├── Http/Middleware/     # SetLocale + EnsureUserIsAdmin
├── Livewire/            # AddToCart, CartTable, CheckoutForm, HeaderCart
├── Models/              # 13 موديلًا (Product, Order, Setting, ...)
├── Notifications/       # OrderPlaced (بريد العميل)
├── Services/            # CartService, CheckoutService, TelegramService, ReportService, StockService
└── Support/helpers.php  # fmt_usd, fmt_syp, syp_from_usd, setting(), media_duration
lang/ar.json, en.json    # كل نصوص الواجهة
database/seeders/        # SettingsSeeder + ShopContentSeeder
public/                  # logo.svg, favicon.svg, manifest, sw.js, icons, placeholders
resources/views/         # واجهة المتجر (Blade) + admin/invoice (فاتورة الطباعة)
scripts/make-icons.php   # توليد أيقونات PWA (GD)
```

## ملاحظات تقنية

- **الدفع غير أونلاين**: يعرض المتجر بيانات وسيلة الدفع (شام كاش/حوالة/عند الاستلام) ويأكد الطلب بكود فريد — يتوافق مع الواقع المحلي.
- **الطلبات الملغاة**: لا تُسترجع كمياتها تلقائيًا (عدّل المخزون يدويًا من اللوحة عند الإلغاء).
- **استعادة كلمة المرور**: غير مفعلة في النسخة الحالية (تحتاج بريدًا يعمل) — يمكن إضافتها لاحقًا.
- **الخطوط**: Tajawal (عربي) وPoppins (لاتيني) — محمّلة محليًا مع البناء عبر Bunny Fonts.
